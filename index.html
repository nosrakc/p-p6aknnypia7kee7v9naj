Export picks

Two codes, one per line: N: = NZB, K: = Keeneland (s = new options please, o = own name). Copy both lines and send them to the session.

Import code

Paste an exported code. Lines starting N: go to NZB, lines starting K: go to Keeneland. Its picks replace the picks for the same sires here. A code with no prefix is read as NZB, only on the NZB tab.
